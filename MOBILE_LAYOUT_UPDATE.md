# ZEZMS v3.4.8 Mobile Layout Update

Build: `20260730-mobile-layout-r2`

This update adds a dedicated responsive phone interface while preserving the
classic desktop layout and the existing application features.

## Mobile improvements

- Compact mobile header with a slide-out navigation drawer.
- Two-column KPI cards matching the supplied phone reference.
- Dense, touch-friendly Sale Out forms matching the supplied phone reference.
- Touch-friendly buttons, fields, and tabs.
- Horizontally scrollable data tables.
- Bottom-sheet dialogs and full-height mobile sign-in.
- Safe-area spacing for modern Android and iPhone devices.
- Updated PWA cache identifier so installed copies receive the new layout.

No database schema, transaction logic, inventory logic, cloud configuration, or
account data was changed by this update.
